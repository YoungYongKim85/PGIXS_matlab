📘 XTrans_GUI (v2.4) 사용 매뉴얼
1. 프로그램 개요
이 프로그램은 X-ray 광학 분야에서 널리 검증된 Zhang Jiang 박사의 refrac 알고리즘을 기반으로 작동하며, 최신 모던 UI가 적용되어 해상도에 상관없이 깔끔한 레이아웃과 고해상도 그래프 저장을 지원합니다.

2. [Step 1] 파라미터 설정 (Parameters)
좌측 패널에서 실험에 사용할 시료의 물리적 정보와 X-ray 에너지 조건을 설정합니다.

Chem. Formula (화학식): 계산할 물질의 화학식을 입력합니다. 대소문자를 엄격히 구분합니다. (예: 물 = H2O, 실리콘 질화물 = Si3N4, 폴리스티렌 = C8H8)

Mass density (질량 밀도): 물질의 밀도를 g/cm3 단위로 입력합니다. (예: 물 = 1.0, 금 = 19.3)

Thickness (두께): 시료의 두께를 um (마이크로미터) 단위로 입력합니다. 이 값은 Transmittance (투과율) 계산 시에만 반영됩니다.

Energy Range (에너지 구간): 계산하고자 하는 빔라인의 Photon Energy (keV) 시작점(Min)과 끝점(Max)을 설정합니다.

# of points: 에너지 구간을 몇 개의 데이터 포인트로 쪼개어 계산할지 결정합니다. 숫자가 클수록 그래프가 부드러워집니다. (기본값: 50)

3. [Step 2] 계산 모드 선택 및 실행
계산하고자 하는 물리량을 Mode 드롭다운에서 선택한 후, 파란색 RUN CALCULATION 버튼을 클릭합니다.

Transmittance: 설정한 두께를 통과한 후의 X선 투과율 (0 ~ 1 사이의 비율).

Critical Angle: 해당 에너지에서 물질의 표면 전반사 임계각 (단위: degree).

SLD (Real): 산란길이밀도(Scattering Length Density)의 실수부. (일반적인 SAXS/GISAXS 분석에 쓰이는 형태)

SLD (Imag): 산란길이밀도의 허수부. (물질의 X선 흡수율과 직결되는 값)

참고: SLD 값들은 직관적인 확인을 위해 10^-6 A^-2 단위로 자동 스케일링되어 출력됩니다.

4. [Step 3] 결과 그래프 분석 (Controls)
계산이 완료되면 우측 Result Plot 영역에 그래프가 생성됩니다. 하단의 Controls 패널을 통해 그래프를 제어할 수 있습니다.

X Scale / Y Scale: 축의 스케일을 linear (선형) 또는 log (로그)로 실시간 변경합니다. 값의 변화 폭이 클 때(예: 투과율 감소) log 스케일이 유용합니다.

Grid On: 체크박스를 클릭하여 그래프 배경의 격자선(Grid)을 켜거나 끌 수 있습니다.

Data Table: 이 버튼을 누르면 현재 그래프에 그려진 정확한 수치 데이터(에너지 vs 계산값)가 깔끔한 엑셀 표 형태의 팝업 창으로 나타납니다. 수치를 직접 확인하고 싶을 때 사용하세요.

5. [Step 4] 데이터 저장 (Save Data)
분석한 결과를 파일로 추출하고 싶을 때 우측 하단의 Save Data 버튼을 클릭합니다.

자동 폴더 생성: 현재 프로그램이 실행 중인 폴더 내부에 현재 계산 모드의 이름(예: SLD_Real)으로 된 하위 폴더가 자동으로 만들어집니다.

저장 파일: 해당 폴더 안에 2열 구조의 데이터 텍스트 파일(.dat)과, 논문/보고서에 즉시 삽입할 수 있는 고해상도(300 DPI) 그래프 이미지(.jpg)가 동시에 저장됩니다.

파일명 예시: Transmittance_8.5_to_15.dat

⚠️ 주의사항 (Troubleshooting)
"Refract function error" 경고창이 뜰 경우: MATLAB 경로(Set Path)에 계산의 뼈대가 되는 refrac.m 함수 파일 및 원자 산란 인자 테이블 파일들(.nff)이 포함된 툴박스 폴더가 정상적으로 추가되어 있는지 확인해 주세요.

그래프가 점선으로만 보일 경우: # of points를 50~100 정도로 충분히 늘린 후 다시 계산 버튼을 눌러주세요.
