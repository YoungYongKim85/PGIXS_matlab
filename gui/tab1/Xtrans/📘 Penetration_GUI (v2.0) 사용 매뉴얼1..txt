📘 Penetration_GUI (v2.0) 사용 매뉴얼1. 프로그램 개요이 프로그램은 표면 산란 실험 시 측정 깊이를 결정하는 핵심 요소인 'X선 침투 깊이(Penetration Depth)'를 시뮬레이션합니다.
 임계각(Critical Angle) 전후로 급격히 변하는 침투 깊이를 시각적으로 확인하여 최적의 실험 입사각을 설정할 수 있습니다.
2. [Step 1] 파라미터 설정 (Parameters)좌측 상단의 Parameters 패널에서 시료의 물리적 특성과 빔라인 에너지를 설정합니다.
Chem. Formula (화학식): 계산할 기판 또는 박막 물질의 화학식을 입력합니다. 대소문자를 엄격히 구분합니다. (예: 실리콘 기판 = Si)Mass density (질량 밀도): 물질의 밀도를 g/cm³ 단위로 입력합니다. (예: 실리콘 = 2.329)Photon Energy (에너지): 3C 빔라인에서 사용할 X-ray 에너지를 keV 단위로 입력합니다. (예: 11.3)Angle Range (입사각 구간): X축에 표시될 입사각(deg)의 시작점(Min)과 끝점(Max)을 설정합니다. (보통 0도에서 1도 사이를 확인합니다.)RUN CALCULATION 버튼: 모든 값을 입력한 후 파란색 버튼을 누르면 즉시 계산이 수행됩니다. (계산 정밀도를 높이기 위해 내부적으로 200개의 포인트로 촘촘하게 자동 분할하여 계산합니다.)3. [Step 2] 광학 상수 확인 (Information)계산 버튼을 누르면 좌측 하단의 Information 패널에 물질의 고유 X선 광학 상수들이 표시됩니다.Delta ($\delta$) & Beta ($\beta$): 물질의 굴절률($n = 1 - \delta + i\beta$)을 결정하는 산란(Delta) 및 흡수(Beta) 상수입니다. 값이 매우 작으므로 파악하기 쉽도록 지수 표기법(예: 1.23e-06)으로 표시됩니다.Critical Angle: 해당 에너지에서의 물질 표면 전반사 임계각(도 단위)입니다. (빨간색 굵은 글씨)4. [Step 3] 결과 그래프 분석 (Controls)우측 Result Plot 영역에 입사각에 따른 침투 깊이 그래프가 나옵니다.그래프 읽기:X축: 입사각 (Incidence Angle, deg)Y축: 침투 깊이 (Penetration Depth, nm)빨간 점선: 해당 물질의 전반사 임계각을 나타내는 수직 가이드라인입니다. 임계각보다 낮은 각도에서는 X선이 표면 수 nm 내외만 훑고 지나가며(Total reflection), 임계각을 넘어서면 기판 깊숙이 침투함을 알 수 있습니다.Y Scale: Y축의 스케일을 linear(선형) 또는 log(로그)로 변경합니다. 침투 깊이는 수 나노미터에서 수 마이크로미터까지 급격히 변하므로 보통 log 스케일로 보는 것이 편리합니다.Grid On: 배경의 격자선을 켜거나 끕니다.Data Table: 시뮬레이션된 정확한 수치 데이터(입사각 vs 침투 깊이)를 팝업 표 형태로 확인합니다.5. [Step 4] 데이터 저장 (Save Data)분석한 결과를 추출하고 싶을 때 우측 하단의 Save Data 버튼을 클릭합니다.현재 프로그램이 있는 폴더에 PenetrationDepth라는 하위 폴더가 자동으로 생성됩니다.지정한 입사각 범위(Min, Max)를 기반으로 파일 이름이 자동 지정되어, 2열 구조의 데이터 파일(.dat)과 고해상도의 그래프 이미지(.jpg)가 함께 예쁘게 저장됩니다.파일명 예시: PenetrationDepth_0_to_1.dat

⚠️ 주의사항 (Troubleshooting)"Refract function error" 발생 시: 이전 계산기들과 마찬가지로 refrac.m 함수 파일과 .nff 원자 산란 데이터베이스 폴더가 MATLAB 경로(Set Path)에 제대로 잡혀 있는지 확인해 주세요.침투 깊이 계산 수식은 기판의 표면 거칠기(Roughness)를 고려하지 않은 이상적인 매끄러운 표면(Ideal flat surface)을 가정한 수치이므로, 실제 실험 시에는 러프니스에 의해 빔이 침투하는 정도가 약간 달라질 수 있음을 참고하시기 바랍니다.
