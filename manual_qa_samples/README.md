# PGIXS Manual QA Samples

These MAT files are synthetic Tab3 smoke-test inputs generated by
`tools/createPGIXSManualQASamples.m`.

- `pgixs_manual_qa_gixs_2dinfo.mat`: synthetic GIXS-style Qxy/Qz 2D-info file.
- `pgixs_manual_qa_trxs_2dinfo.mat`: synthetic TrXS-style Qy/Qz 2D-info file.

Use them only to confirm that Tab3 can load, display, and exercise basic GUI
controls. They are not scientific validation datasets.
